## Featured Projects

### Jaundice Detector

A web app that screens for possible jaundice from a photo of the eye. An eye-detection step runs first and rejects unsuitable images before the classifier sees them, so the model isn't forced to guess on irrelevant input.

| | |
| --- | --- |
| **What it does** | Upload an eye photo and receive a screening result from a trained image classifier |
| **Engineering focus** | Input validation and eye-detection gating to keep predictions meaningful |
| **Stack** | Python, Flask, PyTorch, Railway |
| **Code** | [GitHub repository](https://github.com/GOKULNATH20072008/jaundice_detector) |

> A screening aid only, not a medical diagnosis. Anyone concerned about their health should see a doctor.

### AccessBridge

An accessibility project for people who can't comfortably use a standard keyboard and mouse.

| | |
| --- | --- |
| **Desktop version** | Voice commands and Morse code input for hands-light computer control (Python) |
| **Web widget (in progress)** | A one-switch, auto-scanning widget that lets any site be operated with a single button |
| **Why it matters** | One-switch access removes the need for a full keyboard or mouse |
| **Stack** | Python, JavaScript |
| **Code** | [GitHub repository](https://github.com/GOKULNATH20072008/AccessBridge) |
